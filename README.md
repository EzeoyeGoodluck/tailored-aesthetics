# Tailored Aesthetics — Home Page

A static, responsive home page for Tailored Aesthetics (lip fillers and aesthetic treatments).

- `index.html`: the page (HTML, CSS and JS in one file)
- `logo.jpg`, `lips.jpg`: images

Open `index.html` in a browser, or deploy the folder to any static host (GitHub Pages, Netlify, Vercel).

Before going live, replace `[YOUR PRICE]`, `[YOUR ADDRESS]`, `[CITY]` and `[OPENING HOURS]` in `index.html`.
